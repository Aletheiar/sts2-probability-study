# 实验协议与验收约定

保留原始三个文件，不覆盖历史结果。基准仍为 A=1、B=1、C=2、D=1、T=9、S=10，n=10、h=4。

1. 先用精确分数的正向混合、反向计数和小牌组全排列审计，再执行大规模模拟。
2. 多副本能力牌：设置阶段各激活一张 A/B，保留一张 C，其他揭示牌退出；未揭示 A/B/C/S 都是可消耗非攻击牌。仅一个 A/B 效果生效，每消耗一张仍为 8 格挡和一次抽牌触发。
3. 理论模块采用 Fraction；模拟模块直接独立随机排列实体卡牌索引，不导入理论计算函数。
4. 控制变量分别标注 S/T 替换、普通牌增加/删除、关键牌替换/增加/删除。固定 n、h，不把操作成本解释为游戏成本。
5. 每个主实验配置 200000 次；基准额外 1000000 次；独立重复研究 2000、10000、50000、200000 次的误差尺度。
6. 输出分布、充分统计量、置信区间、种子、环境版本和输入/源文件摘要。概率使用 Wilson 区间，均值使用 CLT 区间；条件量以成功次数为样本量。
7. 收益风险记录 P(Y=0)、总体及条件 90% 分位数、总体变异系数；不把较小标准差自动解释为更强构筑。

实现顺序：数学回归与枚举测试 → 精确及模拟模块 → 审计报告 → 实验配置与运行 → 图形与研究报告 → 完整复验。
