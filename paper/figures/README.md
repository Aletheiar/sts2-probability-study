# 图表说明

所有图均提供300 dpi PNG和嵌入中文字体的矢量PDF。

**01_accessibility**：精确理论可及性曲线；（a）叉号为每组200000次实体排列模拟。改变 N 只增删T；增加关键牌采用固定N替换T。

**03_order_constraint**：基准无顺序/有顺序事件的精确概率。叉号及Wilson区间来自独立1000000次模拟；不能视为战斗执行概率。

**04_payoff_distributions**：条件消耗数的精确混合超几何分布与200000次模拟；右图比较基准条件和总体收益，总体0同时包含未启动和启动后0消耗。

**05_mean_and_sd**：固定N、S/T替换的精确收益期望和标准差，圆点标注S=6、10、14。条件与总体标准差有不同变化方向。

**06_variance_decomposition**：全方差公式的精确分解；操作成本由横轴说明，比较成功后的条件波动与成功/失败条件均值差异。

**09_convergence**：各样本量独立重复30次；RMSE为实际模拟结果，虚线由理论方差给出，尺度随m^(−1/2)变化。

**10_construction_tradeoffs**：比较固定其他数量而增删S与固定N的S/T替换；曲线是精确理论值。只在已建模指标和所示参数范围内解释权衡。
